# Customer Journey: Farmacia Afiliada (Socio Comercial)

## Perfil del Rol
* **Rol:** Farmacia Afiliada (Socio Comercial).
* **Definición:** El punto de venta y dispensación profesional. Actúa como cliente de URUS al usar la plataforma para digitalizar su operación.
* **Foco:** Velocidad operativa y cumplimiento en dispensación.
